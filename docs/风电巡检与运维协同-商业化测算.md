# 风电巡检与运维协同：商业化测算

> 本文件用于课程训练，所有客户、业务量、成本和收益均为合成假设，不构成正式报价、采购建议或收益承诺。金额均为人民币，首年口径。

## 1. 首年内部成本

| 成本块 | 计算依据 | 金额（元） |
| --- | --- | ---: |
| 人力 | 需求调研与方案设计 20 人天 + 开发、集成与测试 80 人天；100 × 1,960 | 196,000 |
| 模型 | 大模型 API 800 元/月 + Embedding API 200 元/月；1,000 × 12 | 12,000 |
| 服务器 | 应用与数据库云主机 800 元/月 + 备份与监控 200 元/月；1,000 × 12 | 12,000 |
| 数据 | 历史资料清洗与标注 12,000 + 知识库构建与第三方接口 12,000 | 24,000 |
| 运维 | 响应与日常巡检 12,000 + 版本迭代 18,000 | 30,000 |
| **合计** | **196,000 + 12,000 + 12,000 + 24,000 + 30,000** | **274,000** |

上述金额是训练分摊假设。正式评估仍需按实际工作量、Token 用量、云资源规格、资料量、接口报价和服务范围复核。

## 3. 报价区间与模式

- 报价下限：274,000 ×（1 + 10% 风险预留）×（1 + 20% 目标加成）＝ **361,680 元**。
- 报价上限：274,000 ×（1 + 20% 风险预留）×（1 + 40% 目标加成）＝ **460,320 元**。
- 报价模式：**项目总价制**，固定首期 5 台风机、8 周、只读边界与人工验收范围。
- 选择理由：首期范围、停止线和验收口径可固定，独立风险预留用于覆盖接口与数据质量的不确定性；年度运维和超范围需求另签。

该区间高于合成访谈中的首期预算上限 250,000 元，因此不能直接作为成交价。下一步应缩小交付范围、重新核实成本或与需求方重谈预算，而不是隐瞒差额。

## 4. 首年 ROI 敏感性复核

原技术方案的收益假设仅用于保持训练口径一致：每天可节省重复归并工时 3 小时、每月 30 天、综合时薪 80 元、工时兑现比例 50%，则首年毛收益为：

`3 × 30 × 80 × 50% × 12 = 43,200 元`。

若以最终项目总价 `P` 作为首年全部投入，且不再重复扣除已包含的模型、服务器和运维费用，则：

- 首年净收益＝43,200 − P。
- 首年 ROI＝（43,200 − P）÷ P × 100%。

| 情景 | 首年投入 P（元） | 首年毛收益（元） | 首年净收益（元） | 首年 ROI |
| --- | ---: | ---: | ---: | ---: |
| 报价下限 | 361,680 | 43,200 | -318,480 | -88.1% |
| 报价上限 | 460,320 | 43,200 | -417,120 | -90.6% |

在该保守假设下，首年不能回本，不支持直接全量采购，只支持先验证真实节时、风险降低和其他可量化价值。节省工时不等于现金回款；若合同未包含部分年度费用，或后续还有新增复核成本，必须另行扣除。真实回本周期需在成交价、续年费用和经签核的收益口径明确后计算。
